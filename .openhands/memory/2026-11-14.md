# 14/11/2026 — Création de LocalLive

Le dépôt ne contenait qu'un README d'une ligne. Application construite **de
zéro** en une session.

## Ce qui a été fait
- Backend FastAPI + SQLite (stdlib sqlite3, pas de dépendance ORM), auth scrypt,
  sessions, moteur FFmpeg 24/7, médiathèque, playlists, scènes, programmation.
- Frontend React + TS + Vite, thème sombre, 8 pages, i18n FR prêt pour EN.
- install.sh / update.sh / backup.sh / uninstall.sh + README.
- 47 tests pytest, tous verts. Parcours complet vérifié dans le navigateur.

## Pièges rencontrés (importants)
- **FFmpeg + stdin** : lancer ffmpeg/ffprobe avec `subprocess` depuis un serveur
  en arrière-plan **bloque tout** (SIGTTIN car le process lit stdin, et sans TTY
  il gèle). Symptôme : la première requête qui lance ffprobe fait geler le
  serveur entier, toutes les requêtes suivantes tombent. Correction :
  `stdin=subprocess.DEVNULL` **et** `-nostdin` dans toutes les commandes FFmpeg.
  C'est LE piège à retenir.
- **Routes FastAPI** : `/api/media/{id}` capturait `/api/media/folders/list`.
  Les dossiers sont donc dans un routeur séparé inclus **avant** media.
- **Sandbox Python corrompu** : `/usr/local/bin/python` (3.13.15) segfaulte sur
  `asyncio.run()` (et donc uvicorn) après quelques heures de session. Ce n'est
  PAS un bug du code : `/usr/bin/python3` (3.13.5) fonctionne. Pour relancer le
  serveur en fin de session : `python3 -m venv /tmp/x && pip install -r
  backend/requirements.txt`, puis lancer avec ce venv.

## Environnement
- `systemd` absent de la sandbox (PID 1 = agent) → install.sh testé en stubbant
  `systemctl` dans un faux PATH, avec des chemins `/tmp`. A fonctionné (service
  généré, app démarre, données préservées au 2e passage, backup + uninstall OK).
- FFmpeg 7.1.5 installé via `apt-get`. `/tmp` vidé à chaque session.
